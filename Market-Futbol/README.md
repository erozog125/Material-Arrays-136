# Market-Futbol ⚽

Este proyecto es una aplicación web para la gestión de un mercado de fútbol, donde se aplican conceptos de manipulación de **Arrays** y objetos en JavaScript.

## 🚀 Funcionalidades
- Visualización de productos deportivos.
- Estructura organizada por módulos (HTML, CSS, JS).
- Manejo dinámico de datos mediante scripts.

## 🛠️ Tecnologías utilizadas
- **HTML5**: Estructura semántica.
- **CSS3**: Diseño responsivo y estilos personalizados.
- **JavaScript**: Lógica de arreglos y dinamismo.
