# Detallitos Harly - Tienda Virtual

Proyecto de tienda virtual para un emprendimiento familiar llamado Detallitos Harly.

La página permite mostrar desayunos sorpresa, anchetas, decoraciones y adicionales personalizados.

## Estructura del proyecto

index.html: estructura principal de la página.
style.css: estilos visuales y diseño responsivo.
market.js: productos destacados cargados desde un arreglo.
shoppingcard.js: lógica del carrito de compras.
breakfast.js: selección de opciones del desayuno personalizado.
checkout.js: datos finales del pedido, domicilio, fecha mínima y envío por WhatsApp.
portfolio.js: botones del portafolio conectados con WhatsApp.
assets/: carpeta de imágenes locales.

## Funcionalidades

Renderizado dinámico de productos desde JavaScript.
Agregar productos al carrito.
Aumentar y disminuir cantidades.
Eliminar productos del carrito.
Guardar el carrito en localStorage.
Seleccionar opciones del desayuno personalizado.
Calcular domicilio según zona.
Validar pedido con mínimo 2 días de anticipación.
Enviar resumen del pedido por WhatsApp.
