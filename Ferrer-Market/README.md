# Ferrer Market 🚀

Tienda virtual de planes de trading desarrollada con JavaScript Vanilla, HTML5 y CSS3.

## 📌 Descripción

Interfaz funcional que permite a los usuarios explorar y gestionar la compra de planes de trading profesional. Los productos se renderizan dinámicamente desde un arreglo de JavaScript y el carrito persiste gracias a localStorage.

## 🛠️ Tecnologías

- HTML5 semántico (`<header>`, `<main>`, `<footer>`)
- CSS3 (Grid + Flexbox, diseño responsivo)
- JavaScript Vanilla ES6+ (arrow functions, template strings, módulos)
- localStorage (persistencia del carrito)

## 📁 Estructura del proyecto

```
Ferrer-Market/
├── index.html          # Estructura semántica principal
├── css/
│   └── styles.css      # Estilos futuristas + responsivos
├── js/
│   ├── products.js     # Arreglo de productos (fuente de datos)
│   ├── cart.js         # Lógica del carrito + localStorage
│   └── app.js          # Renderizado dinámico + eventos
└── assets/             # Imágenes locales de los planes
```

## ✅ Funcionalidades

- Renderizado dinámico de 6 planes de trading desde un arreglo
- Carrito de compras con agregar, aumentar, disminuir y eliminar
- Cálculo del total en tiempo real
- Persistencia del carrito con localStorage
- Diseño responsivo (móvil, tablet, escritorio)
